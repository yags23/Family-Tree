# Family Tree

An Ottoman-themed local-first family tree website.

## Run Locally

```bash
python3 -m http.server 5173
```

Then open:

```text
http://localhost:5173
```

## Notes

- View mode is enabled by default.
- Edit mode is unlocked with the current local password: `Idris`.
- Data autosaves in browser local storage.
- Use **Export** and **Import** to move family data as JSON.
- Static profile photos can be stored in `public/photos` and referenced from the family data.
